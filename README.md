# Greeting Card 
A simple led greeting card

# About the product 
The product is a simple LED greeting card made with simple components easy enough that kids can make it themselves. <br> 
The components used: <br> 
* Coin cell 3V battery <br>
* LED (yellow) <br>
* Copper sheet <br>

# About the circuit 
The circuit was created and the simulation was simulated in Tinkercad. The link for the site is given below: <br> 
* [https://www.tinkercad.com/things/dgS0K5572N4-shiny-lahdi]
